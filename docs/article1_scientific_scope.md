# Article 1 scientific scope

Primary outcome: paired differences in semantic gaze between car and motorcycle on the
same route. Secondary outcomes are vehicle classification from session-level gaze features
and cross-domain gaze prediction. Models must use participant/session/route-aware splits.
Frame-wise random splits and frame-wise independent significance tests are prohibited.

The reduced taxonomy is functional rather than object-maximal. Grounded-SAM2 is secondary;
Mask2Former plus one shared cockpit SegFormer form the intended main segmentation system.
